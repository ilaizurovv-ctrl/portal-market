# Portal Market — Web App

Мини-приложение NFT-магазина для открытия из ShuzaGram.

## Что уже есть
- адаптивный тёмный интерфейс;
- каталог товаров из SQLite;
- профиль пользователя;
- история заказов;
- создание заявки на покупку;
- проверка подписи Web App initData на сервере;
- API администрирования каталога (только для ADMIN_IDS).

## Важно о текущей версии
Покупка создаёт заявку со статусом `pending`. Реальная оплата, списание Stars/денег и автоматическая передача NFT ещё НЕ подключены. Не принимайте реальные платежи на этой версии. Нужна проверка того, что ShuzaGram передаёт стандартный Telegram Web App initData и поддерживает WebApp-кнопки.

## Локальный запуск
1. Установите Python 3.11+.
2. `python -m venv .venv`
3. Активируйте окружение.
4. `pip install -r requirements.txt`
5. Скопируйте `.env.example` в `.env` и задайте переменные окружения.
6. Запустите: `uvicorn app:app --reload`
7. Откройте `http://127.0.0.1:8000` для просмотра интерфейса. Авторизация API работает только при запуске из поддерживаемого Web App с корректным initData.

## Публикация
Для открытия внутри ShuzaGram нужен публичный HTTPS URL. Проект содержит Dockerfile и подходит для хостинга, который поддерживает Docker. Для постоянного хранения SQLite подключите persistent disk и задайте `DATABASE_PATH=/data/portal_market.db`.

## Подключение к боту
Посмотрите `bot_webapp_snippet.py`. После публикации замените `WEBAPP_URL` на выданный HTTPS URL и добавьте обработчик `/market`.

## Администрирование каталога
Используйте API:
- `GET /api/admin/products`
- `POST /api/admin/products`
- `PATCH /api/admin/products/{id}`
- `DELETE /api/admin/products/{id}`

Передавайте заголовок `X-Telegram-Init-Data` с действительными данными Web App. Доступ разрешён только ID из `ADMIN_IDS`.

## Безопасность и следующие шаги
- Никогда не помещайте токен бота во frontend.
- Не публикуйте `.env`.
- Для реальных продаж добавить проверенный платёжный процесс, резервирование/возврат остатков, журнал операций и механизм подтверждённой выдачи NFT.
- Для NFT с реальной стоимостью хранить подтверждение права собственности и историю передачи; одна запись в базе не является передачей NFT.
